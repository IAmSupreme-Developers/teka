 okay how do i set up a db then?
   
  Nothing to set up manually. SQLite creates itself automatically.
  
  When you first run npm run dev and hit any API route that calls getDb(), it:
  
  1. Creates the data/ folder at the project root if it doesn't exist
  2. Creates data/teka.db (the SQLite file)
  3. Runs initSchema() — creates all tables
  4. Runs seed() — inserts the demo playlists, videos, and default user
  
  That's it. The DB is ready.
  
  To add your own content, you have two options:
  
  Option 1 — Direct SQL (quickest for bulk data):
  
  cd /Users/user/Documents/GitHub/streaming/teka
  npx better-sqlite3 data/teka.db
  
  Then run INSERT statements directly.
  
  Option 2 — A simple admin API route (more practical long-term):
  Create /api/admin/video that accepts POST with video data and inserts it. You'd call it from a
  script or a basic admin UI.
  
  For external URL videos the insert looks like:
  
  INSERT INTO videos (name, location, source, playlist_type, playlist_id, idx)
  VALUES ('Death Note E1', 'https://cdn.example.com/dn1.mp4', 'external', 'animes', 3, 0);
  
  Or with quality variants:
  
  INSERT INTO videos (name, location, source, playlist_type, playlist_id, idx)
  VALUES ('Death Note E1',
  '{"720p":"https://cdn.example.com/dn1.720p.mp4","360p":"https://cdn.example.com/dn1.360p.mp4"}
  ', 'external', 'animes', 3, 0);
